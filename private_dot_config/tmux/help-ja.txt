======================================================================
   tmux キーバインド一覧  （プレフィックス: Ctrl+Space）
======================================================================

─── ウィンドウ操作 ────────────────────────────────────────────────
  c          新しいウィンドウを作成（現在のパスで開く）
  n          次のウィンドウへ移動
  p          前のウィンドウへ移動
  w          ウィンドウ一覧を表示・切替
  &          現在のウィンドウを閉じる
  ,          ウィンドウ名をリネーム
  0〜9       番号指定でウィンドウへ移動

─── ペイン操作 ────────────────────────────────────────────────────
  |          左右に分割（現在のパスで開く）
  -          上下に分割（現在のパスで開く）
  x          現在のペインを閉じる
  z          ズーム（全画面 / 元に戻す）
  o          次のペインへ移動
  q          ペイン番号を表示
  {          ペインを前と入れ替え
  }          ペインを後ろと入れ替え
  Space      ペインのレイアウトをローテーション

  h / j / k / l    ← ↓ ↑ → にペインを移動（vim 風）
  H / J / K / L    ペインを左 / 下 / 上 / 右にリサイズ（5単位・繰り返し可）

─── vim-tmux-navigator（プレフィックスなし） ──────────────────────
  Ctrl+h     左のペインへ移動（nvim との間もシームレス）
  Ctrl+j     下のペインへ移動
  Ctrl+k     上のペインへ移動
  Ctrl+l     右のペインへ移動

─── セッション操作 ────────────────────────────────────────────────
  d          セッションをデタッチ（バックグラウンドに退避）
  s          セッション一覧を表示・切替
  $          セッション名をリネーム
  (          前のセッションへ
  )          次のセッションへ

─── コピーモード（Vi キーバインド） ───────────────────────────────
  Enter      コピーモード開始
  v          選択開始
  Ctrl+v     矩形選択に切り替え
  y          コピーしてモード終了
  Escape     コピーモード終了（キャンセル）

─── プラグイン ────────────────────────────────────────────────────
  Ctrl+Space f        tmux-fzf：セッション / ウィンドウ / ペインを検索
  Ctrl+Space Space    tmux-thumbs：画面上のテキストをヒントキーで即コピー

─── resurrect / continuum ─────────────────────────────────────────
  Ctrl+Space Ctrl+s   セッションを手動保存 (tmux-resurrect)
  Ctrl+Space Ctrl+r   セッションを手動復元 (tmux-resurrect)
  ※ 15分ごとに自動保存、起動時に自動復元（continuum）

─── その他 ────────────────────────────────────────────────────────
  r          設定ファイルをリロード
  ?          このヘルプを表示
  :          tmux コマンドプロンプト
  t          時計を表示
  i          セッション情報を表示

======================================================================
  q または Ctrl+c で閉じる
======================================================================
